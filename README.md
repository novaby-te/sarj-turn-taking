# نموذج «متى يسكت الوكيل» — فريقنا في تحدي سرج

نظام يسمع مكالمة عربية (لهجات سعودية وخليجية) كل **٢٠ ملي ثانية** ويقرر: الوكيل الصوتي **يكمّل** (العميل قال «إيه» أو كح أو التلفزيون شغّال) ولا **يسكت** (العميل يبي يتكلم: «لا لا لحظة»، «كم المبلغ؟»)، ومتى **يرد** بعد ما يخلص العميل. وفوقه **وكيل متكلم** للعرض الحي: تكلمه بالمايك، يسكت لما تقاطعه، يسمعك، يرد، ويكمّل.

كل شي يشتغل **على اللابتوب بدون إنترنت** (Mac بمعالج Apple).

## الأرقام (من ١٠٠، بنفس حسبة سرج الرسمية)

| | مكالمات سرج (٢٤) | نفس المكالمات بظروف أصعب (٩٦) | مكالمات جديدة ما شافها (٦٠) |
|---|---|---|---|
| البدائي من سرج | 41.0 | 7.8 | 50.9 |
| **نموذجنا** | **96.5** (اختبار رسمي بالوقت الحقيقي) | **97.6** | **95.1** أول مرة · **99.3** الحين |

## ابدأ (مرة وحدة)

```bash
gh repo clone o6lq/sarj-turn-taking && cd sarj-turn-taking
./setup.sh            # بيئة بايثون + Whisper + بياناتنا المولّدة (~١ GB تحميل)
```

## الأوامر اليومية

```bash
.venv/bin/python -m tools.live                     # صفحة التجربة: مكالمة كاملة / تحديات / اسمع مكالمات سرج
.venv/bin/python -m tools.loop --note "وش غيّرت"   # القياس الكامل + «لوحة قياس سرج.html» في Downloads
.venv/bin/python -m tools.sim --calls GI-D01        # مكالمة وحدة بسرعة
.venv/bin/python -m tools.train_policy              # إعادة تدريب طبقة القرار
.venv/bin/python -m ttbench.play --calls all        # الاختبار الرسمي بالوقت الحقيقي (١٠ دقايق)
python my_system.py --host 0.0.0.0                  # يوم فحص الاتصال والنهائي
```

## قاعدة الفريق (مهمة)

أي تعديل نقيسه بـ`tools.loop`. **إذا رفع «سرج» ونزّل «ظروف أصعب» أو «ما شافها» ← ما نعتمده**، لأن معناه إننا حفظنا البيانات بدل ما نتحسن. وكل تجربة تنكتب في `docs/EXPERIMENTS.md`: وش جربنا، وليش، والنتيجة، والقرار.

## الهيكل

| المجلد | وش فيه |
|---|---|
| `my_system.py` | نقطة الدخول اللي تشغّلها سرج |
| `turn/` | **نموذج القرار**: `policy.py` (القرار وكل الإعدادات) · `asr.py` (Whisper) · `lexicon.py` (القاموس الخليجي) · `vad.py` · `echo.py` · `speaker.py` |
| `convo/` | **الوكيل المتكلم** للعرض: `engine.py` (منطق المكالمة) · `brain.py` (نموذج لغة محلي) · `voice.py` (الصوت) · `scenarios.py` (المكالمات الجاهزة) |
| `tools/` | المحاكي السريع، الفيدباك لوب، اللوحة، التدريب، الضبط الآلي، مولّد المكالمات، صفحة المايك الحية |
| `models/` | Silero VAD + أوزان طبقة القرار المتعلّمة |
| `data/dev` | مكالمات سرج الـ٢٤ (من حزمتهم) · `data/live` تسجيلاتنا بالمايك |
| `docs/` | الشروحات (افتحها بالمتصفح): `02-team-guide.html` **ابدأ فيه** · `01-analysis-and-build.html` · `03-hierarchy-plan.html` |
| `ttbench/` | أداة سرج الرسمية — **لا تعدّلها** |

## المصادر الخارجية وتراخيصها

Whisper large-v3-turbo (MIT، نسخة MLX 4-bit) · Silero VAD (MIT) · Resemblyzer (Apache-2.0) · Microsoft Edge TTS (توليد بيانات فقط، أونلاين) · ESC-50 (CC BY-NC 3.0، بحثي) · Qwen3-14B / Gemma 3 12B (عقل الوكيل في العرض) · numpy/scipy/torch/mlx/onnxruntime/scikit-learn.

## تنبيه

- الريبو **خاص**. بيانات `data/dev` من حزمة سرج: لا تنشرونها.
- بند الملكية في المسابقة: سرج تاخذ ترخيص دائم لاستخدام الحل.
- الملفات الكبيرة (النماذج وأصوات التوليد) في `~/Downloads/sarj-ext-data`، مو في git.
